Target Audience: graduate students, ocean / earth science / biology at MIT, remote sensing data

::: prereq

Prerequisite Knowledge: basic GIS skills, Python from undergrad / informal learning. Attendees will already be proficient programmers in the target language (likely Python). For example, this means they're comfortable with reading in and writing out data, manipulating data structures, using libraries, looping through data structures to accomplish a task, writing functions, and creating basic plots. Ideally they will have taken (or have the knowledge contained in) the Intro to Python Carpentries Lesson

:::
